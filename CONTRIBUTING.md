# Contributing

Thank you for your interest in improving the Zero-Combustion AI Data Center pilot.

## How to contribute
1. Fork the repo and create a feature branch.
2. Test locally on your OS:
   - Windows: double-click `run.bat` or `python simulation.py`
   - Linux / Chrome OS: `bash run.sh` or `python3 simulation.py`
3. Keep `IT_KW = 100` and `DAYS = 7` for reproducible CI results unless proposing a parameter change.
4. Open a Pull Request with a clear description of the change.

## Conduct
Be mission-focused, respectful, and constructive. Semper Fi.
